## Вердикт

**Архитектуру не переписывать.** Saturn (plane + Postgres + Caddy) / exit-ноды (agent + официальные ядра) / клиент только `GET /sub` — правильная схема. Nest, панель на exit, Sing-Box «всё в одном» — откат.

Это **рабочий lab на две ноды одного оператора**, не продукт. P0–P8 в `plan.md` «в проде» значит: у автора на Saturn/titan/mimas крутится. Это не готовность отдавать чужим.

Главная ложь продукта сейчас не Disable (его починили 09-11). Ложь такая:

1. **Квота считает только VLESS.** Hy2 и TT — безлимит, пока кто-то не нажмёт Apply после исчерпания VLESS-счётчика. Hy2-only группа квоту не видит никогда.
2. **Expire на `/sub` пустеет, на ноде пользователь жив**, пока не случится PATCH/revoke/quota-kick/ручной Apply. Свипера по часам нет.
3. **`:19400` — HTTP + Bearer + root `exec` по умолчанию.** Apply тащит REALITY private key и пароли открытым текстом. Firewall — «ops, не код».
4. **Нет CI.** Сломанный `App.tsx` уедет на Saturn, если человек забыл `npm run build`.

Оценка «отдать чужим / продавать планы»: **нет**.  
Оценка «себе, две VPS, 19400 только с Saturn, длинный пароль»: **да, с глазами открытыми**.

## Что реально сильно

- **Контракт `/sub`.** Неизвестный токен → 404. Disable/expire/quota/нет живых нод → пустое 200 + `subscription-userinfo`. Клиент Refresh на этом стоит. Тесты `entitle` / `include` / golden body — лучшие в репо.
- **`desired.State` / push Apply / пересечение** `node.families ∩ group.protocols ∩ Entitled`. Модель правильная. Не Clash-зоопарк инбаундов.
- **`ApplyXrayTraffic`.** Транзакция, `FOR UPDATE`, wrap-around курсора, per-(node,user). Так считают байты у Xray. Дыра — что Hy2/TT туда не входят, не что курсор кривой.
- **Stack validate.** TT не садится на 443 вместе с REALITY+Hy2. VLESS TCP 443 + Hy2 UDP 443 — намеренно.
- **Geo packs.** Каноникализация, отказ `geosite:` / wildcard / IP-as-domain, SHA-256, лимит размера.
- **Share-link render.** Без obfs, REALITY gRPC без vision, `Goodwin-VPN` заголовок только на HTTPS, `PublicHTTPSOrigin` режет `user:pass@`.
- **Xray builder.** gRPC, sniff `routeOnly`, BT + SMTP blackhole, stats, IPv4 DNS. Зафиксировано тестами.
- **TT:** pin `v1.1.0`, `allow_private_network_connections = false`, deeplink с официального бинаря.
- **Инсталлятор панели:** случайный пароль если пусто, `SEED_DEV=0`, `LISTEN=127.0.0.1:8080`, env `0600`, повторный bootstrap не сбрасывает пароль. Инсталлятор ноды сохраняет token.
- **REALITY keygen** — нормальный X25519 + shortId.

Это не случайный скрипт. Это короткая, читаемая панель. Её нельзя путать с Marzban.

## Архитектура: правда

```
телефон  --HTTPS /sub/{token}-->  Caddy:443 Saturn --> plane:8080 --> Postgres
админ    --cookie same-origin-->  Caddy:443 Saturn --> plane:8080

plane --HTTP Bearer--> titan:19400 agent (root) --> systemd: xray, hy2, tt
                   --> mimas:19400 agent
```

Один процесс plane: API + SPA + `/sub` + traffic poller. Нет очереди Apply, нет expire-sweeper, нет worker.

Слабое звено — **средняя стрелка** (plaintext desired + exec). Верхние две — нормальные за Caddy. Нижние ядра — официальные, так и должно быть.

`internal/api/server.go` ~1776 строк: auth, CRUD, enroll, apply, `/sub`, REALITY, static. `admin/src/App.tsx` ~1373 строки: всё UI. Пилить файлы **после** интеграционного теста fake-agent → Apply → `/sub`, не вместо.

Goose в `plan.md` нет в `go.mod`. Миграции — SQL + самописный runner без транзакции и advisory lock. Два процесса plane на старте могут сломать схему.

## P0 — ложь продукта или дыра периметра

### 1. Квота — VLESS-only

`CollectTraffic` пропускает ноду без семьи VLESS (`traffic.go:56-58`). Счётчики двигает только `ApplyXrayTraffic` с email = `user.id`.

Следствия:

- Hy2-only / TT-only группа: `total` никогда не растёт. «Квота 20 ГиБ» в UI — декорация.
- На max-stack пользователь выжигает Hy2/TT после исчерпания VLESS, пока не случится Apply. Loop делает Apply только на переходе `was && !still` по **VLESS-счётчику**.
- Если этот Apply упал (agent down) — `was` на следующем тике уже false. Повторного kick нет. Юзер не entitled в DB и всё ещё на ноде.

Roadmap 2.3 это знает. UI пишет «Hy2/TT не считаются». Для оператора-себя — ок. Для «продаём тариф» — обман.

### 2. Expire не выгоняет с ноды сам

`Entitled` проверяет часы. `/sub` пустеет вовремя. `CollectTraffic` **не** смотрит expire, только quota-crossing. Нет cron «пройти users, Apply групп с истекшими».

Истёкший остаётся в Xray/Hy2/TT до PATCH/revoke/delete/ручного Apply/чужого quota-kick в той же группе.

**Сделать:** раз в N минут `ListUsers` → группы, где кто-то стал `!Entitled` → `applyGroupNodes`. Дешево. Важнее dest/SNI из закрытого 1.1.

### 3. Agent `0.0.0.0:19400` HTTP + exec root

```28:31:cmd/agent/main.go
	cfg := fileConfig{
		Listen:    getenv("AGENT_LISTEN", "0.0.0.0:19400"),
		Token:     os.Getenv("AGENT_TOKEN"),
		AllowExec: getenv("AGENT_ALLOW_EXEC", "1") != "0",
```

`ListenAndServe`, без TLS. Apply шлёт REALITY **private** и пароли. `POST /v1/exec` = `/bin/sh -c` от root. README: «Leave it on». Инсталлятор: `--no-exec` чтобы выключить, по умолчанию вкл. Firewall в код не пишется.

Доступ к `:19400` = remote root + ключи флота.

Exec для своей отладки оставлять можно. Тогда **в инсталляторе** `Listen=127.0.0.1` или nft allow только IP Saturn. Сейчас это фольклор.

### 4. Concurrent Apply last-write-wins

Нет mutex на ноду, нет generation. Create user + traffic kick + второй админ = старый snapshot может приехать вторым и **вычеркнуть нового клиента** с ноды. На двух людях за панелью — не теория.

`Group()` error внутри apply **continue** (`server.go:1298-1302`). Transient DB → пустой список клиентов → kick всех. `UsersInGroup` abort правильный; `Group` — нет.

### 5. `/sub` на каждый Refresh живьём бьёт все ноды группы

Таймаут 2 с, без кэша, плюс `noteNodeAlive` пишет **всю** строку ноды (`UpdateNode` все колонки). Шторм Refresh = DoS plane+agent и гонка статуса/токена.

На 2 нодах незаметно. На 10 — подписка «мигает».

### 6. Дефолты бинаря — lab, не prod

`SEED_DEV=1`, `ADMIN_PASSWORD=change-me`, `SESSION_SECRET=dev-session-secret-change-me` (`cmd/plane/main.go:25-32`). Инсталлятор перекрывает. `go run` / забытый env на открытом порту = публичный `dev-sub-token`.

Логин: нет rate limit, compare по длине не constant-time, cookie 7 дней HMAC без server-side revoke. Смена пароля не инвалидирует сессии. Рядом с Exec это одна украденная cookie = все ноды.

### 7. `GET /v1/users` отдаёт секреты протокола

`store.User` без `json:"-"` на `VlessUUID` / `Hy2Password` / `TTPassword` / `SubToken`. SPA типы их не рисует — JSON всё равно приезжает. XSS в `App.tsx` = дамп всех UUID/паролей.

## Готовность к проду

Честная матрица.

| Вопрос | Ответ |
|--------|--------|
| Свой флот, 2 ноды, 19400 с Saturn, ты единственный админ | **Да**, уже так и живёт |
| Второй оператор / подрядчик с панелью | **Нет** — один пароль, 7-дневная cookie, exec, секреты в JSON users |

## Предложения — порядок, не эстетика

Не пилить `server.go` / `App.tsx` первым коммитом.

**Дни (закрыть ложь):**

1. Expire sweeper + retry quota-kick.
2. Per-node mutex Apply; `Group()` error = abort, не empty kick.
3. Health cache для `/sub`.
4. Login rate limit; SPA 401 → login; не светить VPN-секреты в list.
5. Fake-agent тест критического пути.
6. GitHub Actions: Go test + admin build.

**Неделя (нода не должна требовать няньку):**

7. Installer: bind агента не на `0.0.0.0` без явного флага; документировать nft.
8. Pin ядер + checksum; cert renew hook.
9. Честный Listening.
10. Groups/stack change → Apply.

**Не делать под видом прода:**

- Рефакторинг god-file без теста Apply/`/sub`.
- Dockerize plane «вместо» закрытия 19400.
- Выключать exec, пока обновление ядер = «удали бинарь и Apply» или SSH. Сначала pin+upgrade API, потом `--no-exec` default.
- Стать Marzban. Контракт клиента уже узкий и это преимущество.

## Итог одной фразой

Схему не менять. Панель умеет то, что обещает P0–P8 **на двух своих VPS**. Продом это станет, когда expire и квота совпадут с тем, что слушает 443/8443, `:19400` перестанет быть root-шеллом в интернете, ядра перестанут качаться как `latest`, и появится хотя бы один автотест пути Apply → `/sub`. До того — честный lab, не продукт.
