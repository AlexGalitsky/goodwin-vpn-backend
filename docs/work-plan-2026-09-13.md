## Критерий «можно своим, без краснения»

Волна 0 закрыта **и** полевой прогон:

- Android: error→Retry; чужое приложение не едет в SOCKS без пароля; выкл. TT в системе сбрасывает Home.
- iOS: reopen app не роняет туннель.
- Saturn: истёкший юзер исчезает с ноды без ручного Apply; `:19400` с интернета закрыт.

Это всё ещё не магазин и не «продаём тарифы». Для тарифов нужна волна 2 (P2.1). Для Submit — волна 2 клиента (A2.*).
