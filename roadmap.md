# Что брать дальше

**Дата:** 2026-09-11  
**Контекст:** P0–P8 в проде (Saturn + titan/mimas). Клиент по подписке работает. Это не Marzban и не надо им становиться.

Оценка: **S** — часы, **M** — день-два, **L** — несколько дней и трогает agent на нодах.

Готово, когда фича видна в админке Saturn без README и не ломает `/sub`.

---

## Рамки

Берём только то, что живёт в plane/agent и не меняет контракт `app/` (нет Clash, `ss://`, obfs, xhttp).

Не берём: биллинг, юзер-бот, реселлеры, форки ядер, фейковый сайт на 443 рядом с REALITY, port hopping без теста в клиенте, сканер SNI.

Триал = срок (сутки/неделя), не протокол. Exec не выключаем.

## Явно не в очереди

| Тема | Почему |
|------|--------|
| Clash / Sing-box / `ss://` / Trojan на том же 443 | Ломает тело `/sub` или клиентский парсер. |
| Caddy/Nginx «магазин» на exit :443 | REALITY уже слушает TCP 443. |
| Кастомные форки Xray из админки | Только официальные ядра. |
| Hy2 port hopping | Нет поддержки и теста в `goodwin_vpn_core`. |
| Сканер «чистых» SNI | Saturn ≠ путь телефона. Меняем dest руками (1.1). |
| Биллинг, OTP, ЛК, реселлеры | `plan.md` — не v1. |
| Секреты at-rest / Kill Switch / IPv6 в `app/` | Другой репо, другой аудит. |

## Честный Apply (перед 1.1)

Disable / expire / quota / revoke последнего юзера пушат пустые списки на ноду: VLESS inbound без clients, Hy2/TT **останавливаются**. CORS — только `PUBLIC_SUB_BASE` и Vite `:5173`. `agent.json` — `0600`. Это важнее Settings dest/SNI.

Нужен bootstrap **панели и обеих нод** (agent менялся; токен сохранится).

**1.1:** форма dest/SNI в Инструментах, `PATCH /v1/settings`. Apply больше не перевыпускает ключи из‑за смены dest. Достаточно bootstrap панели + Apply на нодах.
